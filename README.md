# instagram-auto-chat-bot

An AI-powered Instagram chatbot that automatically replies to direct messages using OpenAI GPT.

## Features

- **Automated DM replies** – the bot polls your Instagram inbox and replies to every new incoming message.
- **AI-generated responses** – replies are generated by OpenAI's Chat Completions API (default model: `gpt-4o-mini`).
- **Per-user conversation history** – each conversation partner gets their own rolling context window so replies stay coherent across multiple turns.
- **Session persistence** – Instagram login sessions are cached to `session.json` so the bot does not need to re-authenticate on every restart.
- **Configurable** – model, system prompt, polling interval, and history length are all controlled via environment variables.

## Requirements

- Python 3.10+
- An Instagram account
- An [OpenAI API key](https://platform.openai.com/account/api-keys)

## Setup

```bash
# 1. Clone the repository
git clone https://github.com/iamkoushik21/instagram-auto-chat-bot.git
cd instagram-auto-chat-bot

# 2. Install dependencies
pip install -r requirements.txt

# 3. Configure credentials
cp .env.example .env
# Edit .env and fill in INSTAGRAM_USERNAME, INSTAGRAM_PASSWORD, and OPENAI_API_KEY
```

## Configuration

| Variable | Required | Default | Description |
|---|---|---|---|
| `INSTAGRAM_USERNAME` | ✅ | – | Your Instagram username |
| `INSTAGRAM_PASSWORD` | ✅ | – | Your Instagram password |
| `OPENAI_API_KEY` | ✅ | – | OpenAI API key |
| `OPENAI_MODEL` | | `gpt-4o-mini` | OpenAI model for generating replies |
| `BOT_SYSTEM_PROMPT` | | *(friendly assistant)* | System prompt that sets the bot's personality |
| `POLL_INTERVAL` | | `30` | Seconds between inbox checks |
| `MAX_HISTORY` | | `10` | Max conversation turns kept per user |

## Running the bot

```bash
python -m src.bot
```

The bot will log in, then continuously check for new DMs and reply to them.
